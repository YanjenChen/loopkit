---
description: Show the state of this repository's loopkit runs - batch progress, front, queue.
argument-hint: "[--run NAME]"
---

Run `loopkit status $ARGUMENTS` with the Bash tool and show its output. Also run
`loopkit run list` when the repository may have more than one run.

For more detail, `loopkit summary --run <name>` prints every candidate with its idea, and
`loopkit show <id> --run <name>` prints one candidate in full.
